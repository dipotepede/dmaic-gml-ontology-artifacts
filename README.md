# DMAIC-GML Ontology & Artifacts (Release v1.2.0)

Official public repository for:
**"DMAIC-GML: An ontology for statistical process governance and automated quality gates in reliable artificial intelligence"**

## Structure
* `ontology/`: Core OWL 2 DL TBox schema (`dmaic_gml_tbox.ttl`) and 5 operational ABoxes.
* `queries/`: SPARQL queries answering competency questions CQ1 to CQ5.
* `benchmarks/`: Python reproduction harness for 1,000-cycle latency evaluation.
